# 原片旅行回忆手帐 · 可分发候选版

版本：0.1.0，不含图片的对外版本。用途：给 AI 当天有意义的原照片与简单描述，让它制作带手写文案、纸片和对应装饰的旅行手帐，并保留原照片中的人物原貌。

## 用户如何提供内容

上传原照片，并写一句或一段描述，例如：

> 10 月 5 日，我们坐火车去海边。下午散步、吃冰淇淋，晚上在朋友家吃饭。请做成一张旅行回忆手帐，保留原照片人物。

日期可选，人物关系或纪念日只需在相关时说明。布局、选图、文案、蒙版与核验由 AI 完成。普通用户无需写任何 JSON。

## 使用环境

完整运行需要能查看照片、生成非照片装饰图层、读写本地文件并执行 Python 的 AI 环境。脚本需要 Python 3.10+ 与 Pillow；`requirements.txt` 声明依赖。

支持 Skills 的工具可把整个 `travel-memoir-originals` 文件夹放入其技能目录，并调用 `$travel-memoir-originals`。其他 AI 可先读 `SKILL.md`，再按链接读取参考并执行随附脚本。不要仅复制提示词、再把整张含人物页面交给生图模型重绘；那无法提供这里的原片保真机制。

本包是普通文件夹式 Skill，不是已发布插件。不同工具的技能目录和生图接口由其当前环境决定。核验脚本可单独运行，生成层工具可以替换。

## 包含什么

- `SKILL.md`：从简单输入到最终交付的执行流程。
- `references/style-guide.md`：统一画风、文案和非照片图层提示词。
- `references/composition-schema.md`：任意新照片的合成与蒙版参数。
- `references/quality-checks.md`：人物、纸边、爱心与文字的验收方法。
- `scripts/compose.py`、`scripts/verify.py`：确定性合成与保存后独立核验。
- `agents/openai.yaml`：可选的技能界面信息。

包内不包含过往旅行的家庭照片、私人截图或旧页的固定坐标。用户自己的照片、布局和输出放在另一个工作目录，不写入 Skill。

## 保真范围与验证状态

原照片文件不改动。照片 RGB 只进行方向转正、格式兼容转换与一次等比缩放；边缘形状由独立 alpha 决定。人物保护区不得被剪切、其他照片或装饰覆盖；完整核验区域与同尺寸原片参照逐像素一致。

脚本不能自动判断是否漏圈人物，也不能替 AI 评价纸边美感。成品须经过独立像素核验与视觉复核。只有报告中的区域可以说已核验；不能将局部通过说成全图每一像素与原尺寸照片相同。

通用版的脚本与使用流程已通过公开合成素材的机械验证，并由另一位独立执行者按文档跑通。具体范围见 `references/validation-status.md`。新的真实一天仍需做一张完整页面，确认构图、原片匹配与装饰边缘都能延续已认可的效果。因此当前是可分发候选版，尚未声明任意照片都能一次达到同等审美质量。

本包为不含图片的对外版本：没有第三方参考图、真实照片、测试图片或图片来源信息。只保留 Skill 说明、视觉规范、参数接口、合成与核验脚本。运行时由使用者提供自己的原照片，AI 制作本次非照片装饰图层。
