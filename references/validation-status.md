# 验证状态：0.1.1 候选版

## 本次风格修订

跨平台真实照片试用的输出出现了整齐印刷字、巨幅矩形主照加整齐栏位，以及水彩素材围边等偏离。0.1.1 据此收紧手绘字形、图文邻接、插画笔触和精确修字范围，并增加独立风格验收。修订只涉及设计与验收说明，合成脚本未变；先前脚本检查结果仍只证明对应机械能力。

本版还没有重新完成真实照片的全流程成图验证。文档修订和格式校验不能证明跨平台画风问题已经解决，也不能据现有截图断言人物像素保真。

## 已验证

- Skill 名称、YAML frontmatter 与基本结构通过技能创建工具的校验。开发环境未提供 PyYAML，校验使用 Ruby 的安全 YAML 解析适配；发布脚本无需 YAML 解析器。
- 合成脚本只依赖 Python 标准库与 Pillow；本次实际运行环境为 Python 3.12.14、Pillow 12.3.0。
- 开发自测与独立脚本审查共 73 项 CLI 场景通过；包括原片不同宽高、EXIF 方向、等比缩放、torn/custom/rect、独立完整区域核验、任意非零前景 alpha 遮挡、保存后单像素 RGB/alpha 改动、输入软/硬链接覆盖保护。失败核验不会发布未通过的新成品。
- 26,400 个小尺寸、单像素保护区的几何检查确认保守缩放不会漏掉选中像素。
- 独立执行者仅拿 Skill 和新的公开合成素材，自行建立版式与蒙版，完成两处人物示意、四个独立核验区加两个保护区。保存后像素差异为零，输入文件字节未改。单像素改动、纸片遮头、缺少 audit、覆盖输入等错误按预期失败。
- 独立执行者查看了全页、同尺寸人物对照、完整粉纸爱心、照片搭接与纸边。验证样例使用相对路径；本次不含图片的分发包不附带样例文件。

## 尚未验证

本次修订后的 Skill 尚未用新的真实照片走完“简单描述→动态构图→生成非照片图层→原片合成→独立像素核验→高清视觉验收”的全流程。此前机械样例与试用截图不证明它在任何新照片上都能一次达到既有页面的审美质量。

也未证明自动检查能发现漏圈的脸、细发、被忽略的人物或重要物件；这些仍需执行者实际看图。对各 AI 产品的生图接口与技能安装机制没有统一保证；所用环境必须具备声明的执行能力。

## 对外正式版前的一次真实验收

给原照片与当天短描述，不提供旧页坐标。检查 AI 是否自行匹配照片与事件、按原片比例布局、生成对应装饰、保留完整文字纸片与爱心，并在独立核验通过后查看真实头发、配饰及纸边。保留全部可复现产物；经用户认可后再将该样例及风格调整合入后续版本。公开样例仅使用获准公开的素材。
